# ITIL 4 Foundation Presentation

This directory contains resources for an ITIL 4 Foundation presentation.

## Contents

- `presentation.md`: The slide content in Markdown format. This can be viewed directly or converted to slides using tools like Marp, Reveal.js, or Pandoc.

## Usage

You can present directly from the Markdown file or copy the content into your preferred presentation software (PowerPoint, Keynote, Google Slides).
